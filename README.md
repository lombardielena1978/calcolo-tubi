# Calcolo diametro tubo – piscine

Calcola il diametro del tubo (DN e diametro esterno) a partire dalla portata, in base al circuito:

| Circuito | Criterio velocità |
|---|---|
| Aspirazione | v ≤ 1,7 m/s |
| Mandata | v ≤ 2,5 m/s |
| Sfioro | v ≤ 0,8 m/s |
| Scarico | v ≤ 0,6 m/s |
| Aria | v ≈ 14 m/s (DN più vicino) |

Formula: `Q [m³/h] = (π · (DN/2)² / 1000) · v · 3,6` (DN = diametro interno in mm).

Dati dalla Tabella velocità/portata (UNI 10637).

## Uso

Apri la pagina, inserisci la portata e scegli il circuito.
